# Design references — console screens

The console's operator-facing surfaces were rebuilt against real-app patterns found on Mobbin.
Each row names the pattern, where it came from, and what it changed here.

| Console surface       | Pattern                                                                      | Reference                                                                                                                                                                                                                                                                               | What changed                                                                                                                                                                               |
| --------------------- | ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Incoming alert        | One full-attention sheet with a single primary action                        | [Rivian — alarm triggered](https://mobbin.com/screens/c25ddb40-e4a0-4f77-a9a6-9996a8afa4ed), [Fly Delta — acknowledge modal](https://mobbin.com/screens/d209d80e-1263-4ae7-854b-5d47aad7dff7)                                                                                           | `ui/AlertTakeover.tsx`: an alert from another device on an unresolved incident takes over the screen; "Acknowledge alert" is the primary action, "Show my route" and "Later" are secondary |
| Route guidance        | ETA and distance as headline, next instruction beneath, explicit end control | [Transit — route card](https://mobbin.com/screens/c88b39a9-350c-4467-86ab-1baf574bc4f5), [Apple Maps — instruction banner](https://mobbin.com/screens/fa3e962f-5b20-4705-b9ee-853017b9c8b4), [Grab — navigation](https://mobbin.com/screens/699363da-045c-4dbb-80f3-4ed394f29195)       | `map/RouteCard.tsx`: persistent card over the map with ETA, distance, next leg, leg progress bar, hazard flag, Details and End                                                             |
| Incident detail       | Status pipeline + timestamped timeline                                       | [incident.io — incident timeline](https://mobbin.com/screens/16809a67-3ba1-423b-92a1-63c8eea209d5), [Better Stack — incident timeline](https://mobbin.com/screens/c17baca1-a797-44ab-a5c7-da5d513c31cc)                                                                                 | `panes/IncidentPane.tsx`: Active → Contained → Resolved stepper, severity badge, one timeline merging declaration, updates, alerts, acknowledgements and check-ins                         |
| Readiness             | Headline verdict, then component rows with status dots                       | [OpenAI — service health](https://mobbin.com/screens/d605f83d-3869-4ecc-8874-b913e09e2930), [Better Stack — status page](https://mobbin.com/screens/0d34fbf2-e4c4-451c-ad5d-de3cdf409164), [incident.io — status page](https://mobbin.com/screens/9ac97757-ff30-4b0c-a3dd-ff3f17976053) | `panes/DiagnosticsPane.tsx`: status hero (READY / DEGRADED / ERROR with a count of components needing attention) and a component list with dots and reasons                                |
| Map legend and layers | Legend sheet with icon rows; layer switches                                  | [Shell — legend](https://mobbin.com/screens/fed23c41-7b71-4161-8167-ac0f96257a7f), [Realtor.com — map options](https://mobbin.com/screens/056f687e-8be8-404e-837b-39c20c9f4da3), [The Weather Channel — layers](https://mobbin.com/screens/98764793-2bb7-493d-8e4c-4ff91b9adae4)        | `map/Legend.tsx`: legend of every glyph, route and position state; toggles for assets, doors, labels, alternate route, compartments wired into `FloorCanvas`                               |
| Check-in              | Large, iconed choices with a remembered state                                | [Citizen — check in](https://mobbin.com/screens/476c8be0-1983-4900-89b8-c479ab8a8e2d), [Transit — three-choice safety prompt](https://mobbin.com/screens/c8daff20-2168-4b4c-9a9a-0de67eed32e5)                                                                                          | `panes/CommsPane.tsx`: three-button grid (safe / evacuated / need help) showing this device's current status and time, with a count line                                                   |

Screens are in `docs/screens/`. The drills exercise all six: the two-device relay drill acknowledges
an alert through the takeover, and the offline drill reads the route card and status page.
